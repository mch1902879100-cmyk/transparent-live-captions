# Transparent Live Captions v0.1.0

Initial private release of the separated Transparent Live Captions project.

## Included

- Transparent always-on-top WPF subtitle overlay for Windows Live Captions.
- Local Japanese / English -> Simplified Chinese translation via Hy-MT2 with one-sentence context.
- NLLB int8 runtime fallback.
- Self-contained Windows x64 translation worker and media-session bridge in the release ZIP.
- Local-only config/IPC under `%LOCALAPPDATA%\TransparentLiveCaptions`.
- Synthetic `-QaDemo` route used for privacy-safe Release Harness validation.

## Not included

- Model weights or llama.cpp runtime binaries.
- Personal subtitle history, media titles, configuration, API keys, caches, or logs.
- Cloud translation credentials or cloud caption upload.

## Requirement

Provide a compatible external model root as documented in `docs/MODELS.md`.
