# Transparent Live Captions v0.1.1 — Keep the subtitles. Lose the bulky window.

还在因为 Windows Live Captions 的字幕面板挡住游戏画面而出戏吗？<br>
还在因为只有原文字幕、没有本地双语翻译而苦恼吗？

**Transparent Live Captions v0.1.1** 把 Windows Live Captions 变成一个透明、无边框、始终置顶的双语字幕层，并用本地 Hy-MT2 把日语 / 英语字幕翻译成简体中文。

## 这版最重要的修复

关闭 Windows Live Captions 后，透明字幕宿主现在会继续等待；再次打开 Live Captions 时会自动接管新的进程，不需要重新启动 Transparent Live Captions。

发布前连续做了 3 轮真实 close -> reopen 回归：同一个透明字幕宿主在三轮中保持存活，并重新接管了每次新启动的 LiveCaptions.exe。

## 为什么它适合游戏和视频

- 🎮 **透明无黑框**：原生 Live Captions 窗口移出屏幕，只留下字幕文字。
- 🌏 **原文 + 中文双语**：日语 / 英语字幕可在本机翻译成简体中文。
- 🔒 **Local-first**：默认没有云端字幕上传；Hy-MT2 通过 localhost llama.cpp 运行。
- 🧠 **一句上下文**：利用上一句帮助消歧，但只输出当前句译文。
- ⚡ **针对滚动字幕优化**：句尾、短静默和持续滚动分别有触发策略，避免字幕永远等不到“稳定”。
- 🖱️ **可拖动 / 缩放 / 锁定**：更像 HUD，而不是另一个桌面窗口。
- 🎵 **媒体会话控制**：支持系统媒体信息和上一首 / 播放暂停 / 下一首。

## 本地模型来源

主模型来自腾讯混元官方：

- `tencent/Hy-MT2-1.8B`
- `tencent/Hy-MT2-1.8B-GGUF`
- 推荐 `Hy-MT2-1.8B-Q4_K_M.gguf`
- 上游许可证：Apache-2.0（以腾讯当前官方仓库为准）

模型和 llama.cpp runtime 不打进本 Release，请按 `docs/MODELS.md` 从上游准备。

## Package boundary

Release ZIP includes the transparent overlay, self-contained translation worker, self-contained media bridge, startup/stop/install scripts and user documentation.

It does not include model weights, personal captions, media history, user configuration, API keys, caches or logs.
