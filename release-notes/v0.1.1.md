# 🪟 Transparent Live Captions v0.1.1

**把 Windows Live Captions 变成真正适合游戏、视频和日语内容的透明双语字幕 HUD。**

还在因为 Windows 实时字幕那个大窗口挡住游戏画面而出戏吗？

Transparent Live Captions 直接复用 Windows 自带的语音识别，把原生字幕窗口移出视野，只留下一个透明、无边框、始终置顶、可拖动和缩放的字幕层；日语 / 英语字幕可以继续通过本地 Hy-MT2 翻译成简体中文。

## ✨ 你会感受到的改变

- 🎮 **少一个挡画面的窗口**：屏幕上只保留字幕内容，更像游戏 HUD。
- 🌏 **原文 + 中文双语同屏**：看生肉、JRPG、Galgame、直播时更轻松。
- 🔒 **默认本地翻译**：字幕不需要上传到云端翻译服务。
- ⚡ **专门处理滚动字幕**：句尾、短静默和持续滚动分别有触发逻辑，避免一直卡在“等字幕稳定”。
- 🧠 **一句上下文帮助消歧**：上一句可以作为语境，但模型只输出当前字幕译文。
- 🖱️ **像 HUD 一样自由调节**：拖动、缩放、锁定、字号、颜色、透明度和显示行数都能调。
- 🎵 **顺手控制系统媒体**：支持上一首、播放 / 暂停、下一首。

## 🔁 v0.1.1 最重要的修复

现在你可以直接关闭 Windows Live Captions，再重新打开：

```text
打开 Live Captions
  ↓
透明字幕接管
  ↓
关闭 Live Captions
  ↓
字幕层隐藏，但宿主继续等待
  ↓
再次打开 Live Captions
  ↓
自动重新接管新的 LiveCaptions.exe
```

发布前连续做了 **3 轮真实关闭 → 打开回归测试**，同一个透明字幕宿主在三轮里都保持存活，并成功重新接管新的 Live Captions 进程。

## 🤖 本地模型

默认推荐腾讯混元官方的 **Hy-MT2-1.8B**：

- 官方项目：<https://github.com/Tencent-Hunyuan/Hy-MT2>
- 官方 GGUF：<https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF>
- 推荐：`Hy-MT2-1.8B-Q4_K_M.gguf`（约 1.13 GB）
- 上游许可证：Apache-2.0（请以上游当前仓库 / Model Card 为准）

模型权重和 llama.cpp runtime **不会打包进这个 Release**，请按仓库里的 `docs/MODELS.md` 从上游准备。

## 🚀 快速开始

1. 下载 `transparent-live-captions-windows-v0.1.1.zip` 并解压。
2. 准备 `Hy-MT2-1.8B-Q4_K_M.gguf` 和 llama.cpp Windows runtime。
3. 按 `docs/MODELS.md` 放好目录。
4. 运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Install-Release.ps1 -ModelRoot "D:\AIModels\LiveCaptionTranslation" -Start
```

如果想开机自启，再加 `-RegisterStartup`。

## ⚠️ 边界

本项目自己不做语音识别。声音先由 **Windows Live Captions** 变成文字，再由 Transparent Live Captions 接管显示和本地翻译，因此最终效果仍会同时受到 Windows ASR 和翻译模型质量影响。
